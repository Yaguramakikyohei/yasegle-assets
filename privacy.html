プライバシーポリシー

対象: 投稿ツール「yasegle-publisher」および Instagram / Threads / TikTok アカウント「痩せグル（yasegle.official）」
最終更新: 2026年8月15日

「yasegle-publisher」（以下、本ツール）は、運営者が自身のSNSアカウントへ記事を投稿するために自作した、非公開の個人用ツールです。第三者への提供・販売・公開は行っていません。本ページは、本ツールおよび運営アカウントにおける情報の取り扱いを説明するものです。

1. 本ツールが取得する情報

本ツールが取り扱うのは、運営者自身のアカウントに関する情報のみです。

  • 運営者自身のアカウントID、およびアクセストークン
  • 運営者自身が投稿したコンテンツの公開実績（表示数、保存数、返信数などの集計値）

他の利用者の個人情報は、一切取得しません。 氏名、メールアドレス、電話番号、位置情報、連絡先、端末情報などを収集する機能を持ちません。

2. 利用目的

  • 運営者自身のアカウントへ、あらかじめ作成した記事・画像・動画を投稿するため
  • 投稿の成果（表示数など）を集計し、以後の内容を改善するため

上記以外の目的には使用しません。

3. 保管と管理

  • アクセストークンは運営者の端末内にのみ保存し、外部に送信・共有しません
  • 集計値は運営者の端末内のファイルに保存します
  • 本ツールは外部のデータベースやクラウドサービスへ情報を蓄積しません

4. 第三者提供

取得した情報を第三者へ提供・販売・貸与することはありません。広告配信事業者、解析事業者を含む外部への共有も行いません。

5. 外部サービスとの通信

本ツールは、投稿のために以下の公式APIとのみ通信します。

  • Instagram Graph API（Meta Platforms, Inc.）
  • Threads API（Meta Platforms, Inc.）
  • Content Posting API（TikTok Pte. Ltd.）
  • GitHub API（画像・動画の保管先として運営者自身のリポジトリを使用）

各サービスにおける情報の取り扱いは、それぞれの提供事業者の定めに従います。

6. アカウントで発信する内容について

運営アカウントは、厚生労働省などが公表する公的資料をもとに、食事・睡眠・身体活動に関する一般的な情報を発信しています。

  • 個別の健康相談にはお答えしません。 症状や治療に関するご相談は医療機関にご相談ください
  • 発信内容は診断・治療・処方に代わるものではありません
  • 各投稿には出典を明記しています

7. 削除の求めについて

本ツールは他の利用者の情報を保持していないため、削除の対象となる情報はありません。運営アカウントの投稿内容に関するご連絡は、各SNSの当該アカウント宛にお願いします。

8. 変更

本ポリシーを変更する場合は、本ページを更新し、最終更新日を改めます。

9. 運営者

個人運営。連絡先: 各SNSアカウント「yasegle.official」のダイレクトメッセージ
